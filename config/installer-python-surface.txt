# Files the installer and its host-side service helpers run on the
# interpreter that runs the installer: Python 3.9+ (the router itself needs
# 3.14). Each line is `<mode> <path>`:
#
#   load  - imported by path at install or service time. The 3.9 check loads
#           each one on the installer's interpreter and fails when that pulls
#           in a router package, a module the interpreter does not have, or an
#           unlisted runtime leaf.
#   parse - entry points and subprocess tools. Syntax/compile checked only,
#           never executed: the launchers act at import by design, and
#           tools/disable.py detaches the live router when it runs (2026-09-13
#           incident). Only the installer may run those, as a subprocess.
#
# Owners: tools/check_installer_python39.py and
# tests/test_packaging.py::test_installer_surface_parses_as_python39.
