Opening an unsigned package

These packages do not have a paid publisher certificate. Download only from this page. Follow your organisation’s device policy.

macOS: Open the DMG, then open Install SCG Router. If macOS blocks it, open System Settings → Privacy & Security and allow the app.

Windows: Open SCG Router Setup.exe. Windows may show an unknown-publisher warning. Contact IT if your device blocks it.

Ubuntu: In Files, open Properties for the AppImage and allow execution. Then open it. No separate FUSE installation is needed.

An existing setup keeps its release channel, key, settings and disabled plugins. Need help? Contact Software Combined IT.
