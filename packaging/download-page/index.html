Other setup options

For a platform without a listed installer, or an older installation needing repair, use the current setup script: Windows or macOS and Linux.

These scripts use the stable release for a new installation. An existing installation keeps its chosen update channel.

If your device blocks the installer

The installer is unsigned. Download it only from this page and follow your organisation’s device policy.

On a Mac, open the DMG and then Install SCG Router. If macOS blocks it, use System Settings → Privacy & Security to approve the app. Contact IT if your device does not allow this.

On Windows, open the installer. Contact IT if an unknown-publisher warning or device policy blocks it. Do not turn off device protection.
