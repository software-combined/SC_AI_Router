            What the labels mean

            Done ✓
            The intended people can use it. A named person checked the agreed result against that version.
            In progress / Being reviewed
            The team is building or reviewing the work.
            Ready to publish / On test version
            The work is prepared, but the intended people cannot use the live version yet.
            Live, user check due
            People can use it. Their check of the agreed result is still missing.
            Availability unconfirmed
            The work is reported live, but the supporting record is missing.
            Needs attention
            There is a blocker, a due date has passed, or publication or a user check is still needed.
            Your input
            An open question or check is assigned to a person. The named owner replies in the project chat.
            Not started / Status not recorded
            Planned work and missing information are shown separately. An unknown result never counts as done.
            Deferred
            This work is outside the current plan and its progress counts.

            This page shows recorded facts. Refreshing the page does not verify the work again.
