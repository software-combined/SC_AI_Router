If your device blocks the installer

The installers are not signed yet, so your computer asks once before opening them. Download them only from this page and follow your organisation’s device policy.

Mac: open the DMG, then Install SCG Router. If macOS says it was not opened, choose Done. Open System Settings → Privacy & Security, scroll down, choose Open Anyway next to SCG Router and enter your Mac password.

Windows: if Windows shows “Windows protected your PC”, choose More info. Check that the file name starts with SCG-Router-Installer, then choose Run anyway.

Linux: open the AppImage’s properties, allow it to run as a program, then open it.

Contact Software Combined IT if your device does not allow these steps.
